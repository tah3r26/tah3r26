# 🚀 Featured Projects

## 1. 🚑 ChadAmbuTrack — Ambulance Management & Dispatching Platform

**Projet de Fin d'Études (PFE) — Licence Génie Informatique**

**Contexte :** Gestion des flottes d'ambulances du COUSP et du CHU-RN à N'Djamena, Tchad.

ChadAmbuTrack est une application web destinée à améliorer la gestion des ambulances, la coordination des interventions et le suivi des missions d'urgence.

La plateforme vise à centraliser les informations opérationnelles et à faciliter le travail des acteurs impliqués dans la régulation et la coordination des secours.

### Main Objectives

- Centraliser les appels d'urgence, les patients et les incidents.
- Gérer les ambulances et leurs disponibilités.
- Faciliter la recherche des ressources mobilisables.
- Accompagner le processus de dispatching.
- Préparer et valider les propositions d'affectation.
- Intégrer la géolocalisation et le suivi GPS.
- Suivre les statuts des interventions.
- Conserver l'historique et assurer la traçabilité.
- Présenter des tableaux de bord et des indicateurs opérationnels.

### Business Workflow

`Emergency Call → Patient → Incident → Location → Priority → Available Ambulances → Dispatching → Assignment Proposal → Human Validation → Mission Assignment → Status Tracking → GPS Position → Possible Reassignment → Closure → History → KPI`

### Main Functional Modules

1. User Management & Role-Based Access Control.
2. Emergency Calls, Patients & Incidents Management.
3. Ambulance Fleet Management.
4. Ambulance Availability Management.
5. Dispatching & Mission Assignment.
6. Geolocation & GPS Tracking.
7. Mission Status Monitoring.
8. Operational Dashboard & KPIs.
9. History, Audit & Traceability.

### Software Architecture

Architecture client-serveur structurée en trois couches :

- **Presentation Layer:** interface utilisateur et visualisation des informations.
- **Application Layer:** logique métier, règles de gestion, authentification et API.
- **Data Layer:** persistance des données relationnelles et géographiques.

Django centralise les règles métier. La communication entre le frontend et le backend repose sur les API REST et WebSocket.

### Technology Stack

**Frontend:** React, TypeScript, Tailwind CSS, Redux Toolkit, React Router, Axios, Leaflet, Chart.js.

**Backend:** Python, Django, Django REST Framework, Django ORM, GeoDjango, JWT, Django Channels.

**Database:** PostgreSQL 14, PostGIS, Spatial Indexing.

**Real-Time Communication:** WebSocket, Django Channels.

**DevOps & Infrastructure:** Docker, Docker Compose, Nginx, Linux, GitHub Actions.

### Engineering Focus

- Software Architecture & UML Modeling.
- Relational and Geospatial Database Design.
- PostgreSQL / PostGIS.
- REST API Development.
- Real-Time Communication.
- Authentication & Authorization.
- Business Rules and Workflow Management.
- Docker-based Development Environment.

**Important:** le dispatching constitue une aide à la décision opérationnelle. Les propositions d'affectation sont soumises à une validation humaine conformément aux règles métier.

**Project Type:** Academic PFE · HealthTech · Emergency Management · Geospatial Application.
